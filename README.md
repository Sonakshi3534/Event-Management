🎟️ Event Management Dashboard (PHP + MySQL)

A PHP–MySQL based Event Management System with an Admin Dashboard for managing events and a User View to display events.
The project demonstrates CRUD operations, session-based authentication, and backend integration using PHP.

🚀 Features

🔐 Admin Panel

Admin login (session-based)

Protected dashboard access

Create new events

Update existing events

Delete events

Save events to database

Logout functionality

👤 User Side

View events added by admin

Dynamic event listing from database

Clean UI

🛠️ Tech Stack

Frontend: HTML, CSS, JavaScript

Backend: PHP (PDO)

Database: MySQL

Server: XAMPP (Apache + MySQL)

Version Control: Git & GitHub

📌 Key Learnings

PHP PDO database connection

CRUD operations with MySQL

Session-based authentication

Secure routing

Debugging PHP syntax & logic errors

Git & GitHub workflow
